# All in One QoL

*A Valheim mod by **Team Pscht** · ein Valheim-Mod von **Team Pscht***

**One mod instead of 13.** Taming, planting, crafting from chests, chest labels, quick stack, portals with names and targets, extra slots, a second hotbar, radar, timers, a clock and much more – all in one mod, all configurable in **one** file.

- Every area has its own on/off switch, every key can be changed.
- Every setting shows its **vanilla value** for comparison.
- **English and German:** the mod follows Valheim's language automatically (or choose it in the config).
- **Server sync:** the server sends its settings to all players.

## Features

| Area | What it does (default) |
|---|---|
| **Taming** | Fast taming (5 s) · fast breeding and growing up · offspring can get +1 star · all tames can be commanded · **LAlt+F** all follow · **LAlt+G** all stay · **LAlt+H** call all to you · lost tames come back on their own (from 40 m) · tames follow through portals · tames are rescued instead of dying (not when killed by a player) · tame and wild animals eat from chests nearby |
| **Planting** | Plant everything in every biome · growth time in minutes · **cultivator grid**: plant in a grid with visible lines, size with Ctrl + arrow keys or Ctrl/Alt + mouse wheel, rotate the whole grid with the mouse wheel, shows how many seeds you have and marks plants red you lack seeds for · plant **berry bushes, mushrooms and thistles** with the cultivator (5 each, they grow back after harvesting, hover shows the time left) |
| **Craft from chests** | Crafting, building, smelting and buying use materials from chests nearby (50 m) |
| **Player** | Carry weight · build distance · interaction distance · auto-pickup range · **bigger inventory** (up to 5 extra rows) |
| **Items** | Stack size ×20 · weight ×0.5 · no movement penalty from gear · items float |
| **Stations** | Seconds per item and capacity for smelter, blast furnace, kiln, spinning wheel, windmill, eitr refinery · fermenter and beehive time · fill **from chests**, **Shift + E** = fill to max · kiln only takes normal wood |
| **Fires** | No fuel needed (campfires, braziers, all other fires – each on its own) · no smoke |
| **Building** | No rain/water damage · bigger workbench range · no roof needed · auto repair gear and buildings at the workbench · build in dungeons · protect the ground around portals |
| **Skills** | XP factor for every skill · own skills **Exploring** (map reveal radius grows), **Sailing** (faster ship) and **Taming** (stronger tames) |
| **Comfort** | **Pause in multiplayer** when everyone is in the Esc menu · **craft amount** (craft several at once) and **×N** behind each recipe · **recipe groups** and **sort buttons** (health, stamina, eitr / damage, armor, block) at cooking and crafting stations · no mist · auto-closing doors · ballistas ignore players and tames · keep weapons while swimming · remove carts and ships with the hammer |
| **Mass harvest** | Harvest all plants of the same kind nearby, beehives too |
| **Chests** | Size per chest type · **label [K]** with a **sign on the chest** (text and item picture) · sign side **[L]** · picture **[G]** · **quick stack [P]** · **sort [O]** · **delete item [Del]** · hotbar protection |
| **Workbench extensions** | Extensions may stand farther away and right next to each other |
| **Portals** | **E** opens a window: **name**, **target** (all portals of the world) and **default portal** (new portals connect to it automatically) |
| **Smart chests** | Items move to the chest that already holds the same item or group · hold **LAlt** = store normally |
| **Timers** | Time left on plants, fermenter, beehive, taming, love, pregnancy, growing up |
| **Day, night and clock** | Length of day and night · clock at the top with day number, Valheim time and real time |
| **Extra slots** | **4 armor slots**, wishbone/wisp, **belt** (works in addition!), trinket, **key slot** (swamp crypt key and other door keys), **3 food slots** (eat with **Ctrl+Y / X / C**), **shield slot** (shield is equipped with one-handed weapons) · **second hotbar** with 8 slots (**Alt+1 … Alt+8**) · after death everything goes back into its slots |
| **Radar** | Dungeon entrances, villages, ruins, tar pits, runestones, shipwrecks, ores, bushes … as pins on the map · window with **F7** |
| **Inventory helpers** | **Favorites**: middle-click an item – used items are refilled from chests nearby · **compare** weapons, shields and armor in the tooltip · keep weapons in hand at stations · **colored durability bar** |
| **Trophies** | Trophy chance of all monsters 200 % (100 = normal) · optional minimum chance (100 % = always a trophy) |
| **Death** | Skill loss factor · keep equipped gear · optionally keep hotbar and food |
| **Sea serpents** | Spawn chance in % (100 = normal) and max number in the ocean |
| **Steam achievements** | Achievements also work with mods and cheats · unlocks achievements you already earned · removes the "cheated" mark from items |
| **Quick connect** | Button in the main menu that joins your favourite server directly (address and optional password in the config) |

| Key | Function |
|---|---|
| **E** at a portal | Portal window (name, target, default portal) |
| **K** | Label a chest (look at it) |
| **L** | Move the chest sign to the next side |
| **G** | In an open chest: put the picture of the item under the mouse on the sign |
| **P** | Quick stack into chests nearby |
| **O** | Sort inventory and open chest |
| **Del** | Delete an item in the inventory |
| hold **LAlt** | While storing: the item stays in the open chest |
| **LAlt+F / G / H** | All tames follow / stay / come to you |
| **Shift + E** | Fill a station to max |
| **Ctrl + arrow keys**, **Ctrl/Alt + mouse wheel** | Change the cultivator grid size |
| **F7** | Radar window |
| **Alt+1 … Alt+8** | Use an item from the second hotbar |
| **Ctrl+Y / X / C** | Eat from food slot 1 / 2 / 3 |
| **Middle click** in inventory | Mark / unmark an item as favorite |

## Installation

- Install with a mod manager (r2modman / Thunderstore Mod Manager). Needs **BepInEx** and **Jotunn**.
- **Every player** needs the mod.
- **Dedicated server:** install the mod there too. The server provides the portal list, the default portal and the settings (server sync).

## Config

File: `BepInEx\config\pscht.allinoneqol.cfg` (or the config editor of your mod manager).

- **Language:** section `00 - Sprache / Language` → `Auto` (follows Valheim), `Deutsch` or `English`. The descriptions change after a restart.
- Section and setting **names stay German** (so your values are kept), the **descriptions** are in your language.
- **Server sync:** with sync on, the server's values replace the players' values while they are connected. Keys, clock, extra slots, radar, inventory helpers and language are set by each player.

**Coming from XPortal:** set your portal targets once again with E.

## Problems?

`BepInEx\LogOutput.log` shows at start: `All in One QoL 1.2.0 geladen (X Patches OK, Y fehlgeschlagen)`. If a patch fails, only that feature is off – everything else keeps working.

# Deutsch

## Installation

- Mit einem Mod Manager installieren (r2modman / Thunderstore Mod Manager). Braucht **BepInEx** und **Jotunn**.
- **Jeder Spieler** braucht den Mod.
- **Dedizierter Server:** den Mod auch dort installieren. Der Server liefert die Portal-Liste, das Standard-Portal und die Einstellungen (Server-Sync).

## Konfig

Datei: `BepInEx\config\pscht.allinoneqol.cfg` (oder der Konfig-Editor im Mod Manager).

- **Sprache:** Abschnitt `00 - Sprache / Language` → `Auto` (wie Valheim), `Deutsch` oder `English`. Die Beschreibungen wechseln nach einem Neustart.
- **Server-Sync:** ist er an, ersetzen die Werte des Servers die Werte der Spieler, solange sie verbunden sind. Tasten, Uhr, Extra-Slots, Radar, Inventar-Hilfen und Sprache stellt jeder selbst ein.
